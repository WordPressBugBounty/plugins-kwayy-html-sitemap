# 🗺️ Kwayy HTML Sitemap

Generate a clean and SEO-friendly **HTML Sitemap** for your WordPress website.

Kwayy HTML Sitemap helps you create a complete sitemap page that improves website navigation for both visitors and search engines. Unlike XML sitemaps, this plugin creates a fully readable HTML sitemap page directly on your website.

The plugin supports:

* ✅ Pages
* ✅ Posts
* ✅ Custom Post Types
* ✅ WooCommerce Products
* ✅ Any registered post type

Simply add the shortcode below to any page and your sitemap will be generated automatically.

```shortcode
[kwayy-sitemap]
```

# 📦 Installation

## Step 1

Install and activate the plugin from the WordPress Plugins page.

---

## Step 2

Create a new page such as:

```text
Sitemap
```

---

## Step 3

Insert the shortcode below into the page content:

```shortcode
[kwayy-sitemap]
```

---

## Step 4

Publish the page.

Your HTML sitemap is now ready 🎉

---

# ⚙️ Plugin Settings

You can customize the sitemap from:

```text
Settings → Kwayy HTML Sitemap Options
```

Available options include:

* Show or hide post types
* Sort post types with drag & drop
* Exclude posts from sitemap
* Rename custom post type titles
